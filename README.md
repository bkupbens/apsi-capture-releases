# APSI Capture — releases

Built, signed and notarised DMGs of **APSI Capture**, the photographer's Mac app
from Action Plus Sports Images, and `appcast.xml`, the feed the installed app
checks for updates. Nothing else lives here.

Install: open the newest `APSI-Capture-*.dmg`, drag *APSI Capture* to Applications.
The app updates itself from then on (APSI Capture menu → Check for Updates…).
